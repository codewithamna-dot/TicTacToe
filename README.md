# Tic Tac Toe Game in Java

A simple **console-based Tic Tac Toe game** written in Java. The game allows two players to enter their names, take turns choosing boxes from 1–9, and play again after the game ends.

## Features

- Two-player Tic Tac Toe game
- Player names are entered at the beginning
- Uses `X` for Player 1 and `O` for Player 2
- Displays the board in the console
- Checks rows, columns, and diagonals for a winner
- Detects a draw when all 9 moves are completed
- Allows players to restart the game
- Uses Java's `Scanner` for user input


## How to Play

1. Enter Player 1's name.
2. Enter Player 2's name.
3. Player 1 chooses a box from **1 to 9** and plays with `X`.
4. Player 2 chooses a box from **1 to 9** and plays with `O`.
5. The first player to get three marks in a row, column, or diagonal wins.
6. If all boxes are filled without a winner, the game is a draw.
7. Choose `Y` to play again or `N` to exit.
